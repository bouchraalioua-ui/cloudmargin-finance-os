# CloudMargin — Finance Operating System

Independent, synthetic-data financial analysis exercises inspired by Vercel's public October 2026 AI Gateway, agentic infrastructure, and enterprise announcements.

## Modules
- Analyst desk: sourced business signals and work assignment queue.
- FP&A: twelve-month driver-based revenue and direct-cost plan and reforecast.
- Product Finance: agent execution unit economics, consumption assumptions, and compute margins.
- AI Gateway: provider cost and model-mix exploration, explicitly distinct from Vercel revenues; original synthetic AI cost variance bridge.
- GTM Finance: enterprise booking ramp and direct servicing contribution.
- Strategic Finance: discounted cash flow investment decision.
- Executive Finance Brief: linked readout and copyable memo.

## Important limitations
Neither the forecast nor the unit costs, customer fees, deal economics or investment estimates are actual Vercel results. The public Vercel reports support which topics to explore only. The original CloudMargin usage.json is used for historical synthetic bridge analysis.

## Run
`npm install` then `npm run dev` or `npm run build`.
